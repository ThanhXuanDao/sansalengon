# Roadmap — Lộ trình thực hiện

## Tháng 1 — Nền tảng

**Mục tiêu**: Hệ thống chạy được, có deal đầu tiên, test thị trường

- [ ] Đăng ký tài khoản AccessTrade, lấy API key
- [ ] Đăng ký Shopee Affiliate (nếu cần)
- [ ] Build backend: sync deal tự động từ AccessTrade
- [ ] Database: lưu sản phẩm, deal, lịch sử giá
- [ ] Website cơ bản: hiển thị deal theo ngách (ngách đầu: thời trang)
- [ ] Bắt đầu post Facebook thủ công để test phản hồi thị trường
- [ ] Tạo Zalo OA

---

## Tháng 2 — Mở rộng kênh

**Mục tiêu**: Kênh phân phối hoạt động ổn định, có data để tối ưu

- [ ] Auto-generate ảnh deal (Puppeteer screenshot hoặc Canvas API)
- [ ] Zalo OA: kết nối API, setup broadcast tự động
- [ ] Dashboard nội bộ: xem deal nào click nhiều, kênh nào hiệu quả
- [ ] SEO: submit sitemap, tối ưu meta tag từng trang sản phẩm
- [ ] Tối ưu bộ lọc deal dựa trên click-through rate thực tế

---

## Tháng 3–4 — Thêm ngách thứ 2

**Mục tiêu**: Validate hệ thống có thể scale theo ngách

- [ ] Thêm ngách: Điện tử / Đồ gia dụng (chỉ thêm config)
- [ ] Tạo kênh phân phối riêng cho ngách mới
- [ ] So sánh hiệu quả giữa các ngách → ưu tiên ngách tốt hơn

---

## Tháng 5–6 — Tối ưu & Scale

**Mục tiêu**: Hệ thống ổn định, thu nhập consistent

- [ ] Thuê cộng tác viên post Facebook nếu cần
- [ ] Thêm ngách thứ 3
- [ ] TikTok: thử nghiệm video review deal (nếu muốn)
- [ ] Tối ưu conversion: A/B test nội dung, thời điểm post
- [ ] Theo dõi hoa hồng theo ngách → phân bổ effort hợp lý

---

## KPIs cần theo dõi hàng tuần

| Metric | Mục tiêu tháng 2 | Mục tiêu tháng 6 |
|---|---|---|
| Deal được sync/ngày | 50+ | 500+ |
| Click affiliate/ngày | 100+ | 2,000+ |
| Subscriber Zalo OA | 500+ | 10,000+ |
| Hoa hồng/tháng | 1tr+ | 20tr+ |
